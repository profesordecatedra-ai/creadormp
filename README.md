# Vocalis Studio — versión sencilla

Página estática, igual que tus otros proyectos: **no necesita variables ni configuración en Netlify**.
Sube el contenido de esta carpeta a GitHub (con las carpetas `assets`, `css` y `js`) y Netlify la publica sola.

## Privacidad
- Tus empresas, guiones y voces se guardan **en el navegador del equipo donde trabajas**. Nada se sube a internet.
- Quien abra tu dirección ve un estudio vacío: no puede ver tus datos.
- En **Ajustes → Clave de entrada** pones una clave para que el estudio la pida al abrirlo en ese equipo.

## Usarlo en otro equipo
**Ajustes → Exportar respaldo** en un equipo, y **Importar respaldo** en el otro.
La API key de Gemini se pone una vez en cada equipo (no va en el respaldo).

## Lo demás
El manual de uso completo explica Empresas, Automático, Guiones, Voz, Radio y Ensamblar.
